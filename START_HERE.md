# Початок роботи

1. Встановіть залежності за [README](README.md#встановлення).
2. Завантажте дані змагання й виконайте `cvlab prepare`.
3. Перевірте [правила підготовки кадрів і розмітки](docs/PREPROCESSING.md).
4. Для навчання оберіть конфігурацію у `configs/` або YOLO launcher.
5. Для фінального ансамблю використайте [опис інференсу](docs/INFERENCE.md).

Результати: [журнал Kaggle](experiments/leaderboard_results.json). Звіт: https://yelgor.github.io/AI_lab2/.
